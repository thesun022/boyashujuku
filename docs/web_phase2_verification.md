# Web 第二阶段首页仪表盘验证

实验环境为 Windows 11、Python 3.14.6、MySQL 8.0.46 和 Microsoft Edge。仪表盘由 `/api/dashboard` 返回数据，工作量图表直接使用 API 返回的类型与累计分钟。[Chart.js 4.5.1 发布记录](https://github.com/chartjs/Chart.js/releases/tag/v4.5.1)

## 数据口径与权限

| 指标 | 口径与可见范围 |
| --- | --- |
| 当前成员及届次成员 | 人员管理员、项目管理者可看。在任成员取自 `v_current_members`。默认选择入届年份不晚于当年的最新届次，同时可切换到已登记的其他届次 |
| 进行中活动 | 已达到活动开始时间且可见项目中仍有未完成项目。进度仅统计可见的必需项目。项目管理者按活动或项目创建归属查询，其他成员通过在任期间尚未结束的任务分配取得可见项目 |
| 待处理任务 | 管理范围或分给本人的待处理、进行中和受阻任务去重计数 |
| 待我审核 | `v_pending_reviews` 中当前实际交接给本人的版本 |
| 已发布作品 | 可见项目中已经正式发布的项目 |
| 工作量 | 统计实际贡献，项目管理者按所管项目汇总，其他成员按本人汇总。图表展示分钟，可展开查看分钟及记录数 |
| 相机状态 | 相机管理者查看 `v_equipment_status` 的状态分类计数 |

新增的数据库对象是只读过程 `sp_web_dashboard` 及其调用权限，保存在 [仪表盘扩展 SQL](../database/12_web_dashboard.sql)。过程从会话摘要取得操作者，重新查权限后才返回对应指标。

| 场景 | 实测结果 |
