# 角色与操作指南

运行 [本机演示命令](../README.md) 后，在 Edge 的普通窗口和 InPrivate 窗口分别登录需要的角色。换成其他身份可先点击右上角的「退出登录」。演示密码由启动者现场设置。

| 账号 | 常用页面 |
| --- | --- |
| `demo-web-admin` | 人员管理、成员履历、技能、系统管理、角色权限、操作日志、备份与恢复 |
| `demo-minister` | 首页、活动项目、任务、素材、审核、相机、统计 |
| `demo-writer`、`demo-layout`、`demo-photo-a`、`demo-video` | 本人指派、实际参与、获授权项目的素材与作品版本 |
| `demo-chief` | 本人待审、责编任务、审核意见、交接时间线和本项目推文发布 |
| `demo-second`、`demo-third` | 当前实际交接给本人的待审成果、预览材料和本人审核历史 |

## 人员、项目和任务

1. 管理员在「人员管理」新增人员，可继续登记届次、加入和初始职务。用「技能」为成员分配技能，在「履历与工作量」查看历届任期、职务变化和实际投入。通过「系统管理」为人员开设账号并授予角色。
2. 部长在「宣传活动」新建活动并决定是否启用三审，随后在「项目与进度」新增推文、视频或摄影项目。选择审核发布的项目后，在「设置审核人」为各必需阶段指定人员。部长独剪的视频从主编开始，二审总是必需，三审随活动开关。
3. 在「任务管理」创建所需任务，打开详情后使用「分配人员」。可逐一添加允许多人参与的拍摄或剪辑任务成员。由参与成员打开任务详情登记实际投入，部长也可为成员登记。任务完成前须有实际工作记录；修改状态保留时间线。
4. 「办理退出」关闭任期和开放分配，并使账号停用。再次加入时可登记新任期，并由管理员按需重新启用账号。
5. 改派后遇到单人任务的工时冲突，点击报错里的「查看实际参与记录」，按记录编号、姓名和分钟核对。具有代登记权限的项目负责人在该行点「作废工时」，填写原因并确认。任务详情保留作废记录，统计和送审资格只读取有效工时。新负责人随后登记自己实际投入的分钟数。

## 推文与视频审核演示

### 使用现有的视频送审案例

1. 用 `demo-third` 登录，在「审核管理」打开「部长亲自剪辑视频」，填写意见并选择「退回」。
2. 换 `demo-minister` 登录，在「视频管理」打开同一项目的版本页。进入「项目素材」，上传一份 MP4 或 WebM 成片后回到版本页新建版次。旧版审核意见仍在时间线。
3. 分别使用 `demo-chief`、`demo-second`、`demo-third` 审核新版本。登录 `demo-minister` 后，从「审核管理」打开待发布版本，填写发布渠道和 HTTPS 链接。

### 从新活动开始演示推文

1. 部长在活动下新建审核发布型推文，配置部长、主编、二审人和必要的三审人，建立并分配撰稿、照片和排版等任务。
2. 撰稿和排版成员登记实际工作；在素材页上传 DOCX 原稿、照片并添加秀米链接。排版成员提交秀米版。部长通过后，排版成员可提交绑定微信草稿预览的新版。
3. 主编和老师在各自待审列表通过或退回。主编或老师退回后，指定部长在交接详情将其转回原提交人。完成修改后从秀米版重新提交，旧版本与意见随历史保留。
4. 终审通过后，推文进入「待发布」。项目指定的在任主编在公众号实际发布后，从工作台点击「登记发布」，核实正式链接和渠道并确认。系统将有有效工时且状态正常的推文必做任务一起结为「已完成」。若必做任务缺少工时、受阻或已取消，页面指出需要核实的任务名称。

## 从工作台直接办理

「工作待办」逐条显示作品名、版本和审核阶段。点「审阅」即到这个版本的素材、历史意见与通过／退回表单。部长可直接转交退回意见，排版员可直达修改重提或提交微信草稿，主编可直达待发布推文。任务行的「办理任务」进入该任务的分配和工时详情。每栏展示最多五项，可点「查看全部」；只有一个待审版本或待处理任务时，点击对应数字卡片也能打开它。

## 素材、设备和统计

- 素材按活动、项目和类型筛选。标题链接可打开受保护的文件预览或外部 HTTPS 预览；「下载」取原件。「引用详情」列出项目和版本。历史版本与项目仍引用的素材由数据库事务保护。
- 「相机管理」登记自有、购入或借入相机。打开「使用与借还记录」预约、签出、归还或取消预约。设备与预约时间冲突时界面会提示，外借归还在设备列表办理。
- 「统计分析」可切换人员、届次、工作类型、活动作品或设备使用口径，按日期和关键词查询。审核次数计入记录数，实际投入按分钟独立累计。同一任务的多次记录合并计算参与事项数。
- 管理员可在「操作日志」按动作查询关键业务历史。「备份与恢复」提供独立文件归档、全量备份、Binlog 恢复的入口说明，也可重试已解除引用的文件清理。
