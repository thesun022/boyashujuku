## 推荐架构

**后端采用 Python + Flask + PyMySQL，页面采用 Jinja2 + Bootstrap 5 + 少量原生 JavaScript，图表采用 Chart.js。** 同一个 Flask 应用负责页面模板和同源 JSON API。浏览器通过 HTTP 请求后端，应用通过带参数的 SQL 调用 MySQL。由同一套模板统一实现中文左侧导航、用户顶栏、数据表格、状态标签和历史时间线。

- **部署**采用项目虚拟环境、锁定的 Python 依赖和 Waitress，默认绑定本机回环地址。通过虚拟环境内的可执行文件启动，适合当前 Windows 环境。Waitress 会缓冲请求体，上传视频时需配合临时磁盘空间和请求大小配置测试。 [Flask 的 Windows 部署说明](https://flask.palletsprojects.com/en/stable/deploying/waitress/) · [Waitress 配置参数](https://docs.pylonsproject.org/projects/waitress/en/stable/arguments.html)
- **数据库接入**采用显式参数化 SQL。任务分配、版本提交、审核、发布和相机预约复用已验证的存储过程，列表和统计优先复用现有查询视图。MySQL 账号使用 `caching_sha2_password` 时，驱动依赖按其认证要求配置。 [PyMySQL 安装与认证说明](https://pymysql.readthedocs.io/en/latest/user/installation.html)
- **前端交付**把锁定版本的 Bootstrap 和 Chart.js 编译资源随项目分发，页面在本机或离线演示时可加载。图表由查询 API 返回当前数据库数据。 [Bootstrap 编译资源](https://getbootstrap.com/docs/5.3/getting-started/contents/) · [Chart.js 脚本接入](https://www.chartjs.org/docs/latest/getting-started/integration.html)
- **认证与权限**验证 `account` 的 Argon2id 哈希和启用状态，由服务端会话确定操作者。API 同时检查功能权限和行级范围，例如部员只能访问分配给本人的任务、审核人只能处理交给本人的当前版本。写入请求验证 CSRF，退出使会话失效。通过命令行交互式初始化管理员凭据，后台使用专用最小权限 MySQL 账号。 [Flask 会话与安全说明](https://flask.palletsprojects.com/en/stable/web-security/)

### 文件访问

文件存入可配置的服务器目录，目录位于静态资源范围之外。数据库存储元数据、独立生成的存储键、SHA-256 和项目或版本引用。上传按类型校验扩展名和内容，并按配置限制大小；随机存储键防止同名覆盖。照片可直接预览，视频通过鉴权后的媒体接口播放，Word 提供内容预览和原件下载。

预览和下载统一通过后端授权。清理素材时核查项目和历史版本引用；清理与新增引用必须对同一文件串行化，失败后可安全重试。文件存储和 MySQL 分别备份。存储目录、文件凭据及服务配置由本机运行环境提供。

## 开发顺序与验收

各阶段使用隔离 MySQL 实例和虚构数据，同时检验正常操作、直接调用 API 的权限边界和数据库最终状态。

| 顺序 | 模块 | 阶段验收 |
| --- | --- | --- |
| 1 | 登录与权限 | 从浏览器登录各身份，退出后会话失效。错误密码、停用账号和直接越权请求得到明确结果 |
| 2 | 首页 | 人员、活动、任务、审核、发布、相机和工作量来自实际查询 |
| 3 | 人员 | 新增、编辑、入职、退出、届次、职务历史和技能维护。退出后保留历史、限制新指派 |
| 4 | 活动与任务 | 创建和修改活动，分配单人或多人任务，查看实际参与和状态历史；并发修改返回冲突 |
| 5 | 素材 | Word、图片和视频上传、预览、下载；验证同名、超限、无权限和有引用删除 |
| 6 | 推文与视频 | 关联新闻稿、照片、预览链接及视频成片，显示版本链和发布信息 |
| 7 | 审核 | 跑通退回、修订、重提、两审或三审及发布；部长亲自剪辑交主编；按审核身份限制直接 API 请求 |
| 8 | 相机 | 新增设备，预约、借还及查看状态；验证重叠预约和未归还时的冲突 |
| 9 | 统计 | 按人、届次、工作类型、活动和设备查询，抽样比对图表与 SQL |
| 10 | 系统管理与交付 | 验证账号、角色、日志和备份说明，提供源码、初始化 SQL、依赖及启动说明、管理员初始化、角色指南和跨角色验收记录 |

本轮开发覆盖表中全部模块，业务写入通过权限检查和已有事务规则，模块场景均在独立 MySQL 上验收。阶段记录见 [认证验证](web_phase1_verification.md)、[仪表盘验证](web_phase2_verification.md) 和 [完整 Web 验收](web_final_verification.md)。正式库扩展详见 [部署与迁移说明](web_deployment.md)。
