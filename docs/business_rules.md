# 业务规则

## 人员与权限

- 组织层级从高到低依次为三审人、二审人、主编、部长、部员。审核顺序根据项目类型执行。
- 人员和任期分开保存。每人最多一个开放任期。同一人可以退出后再次加入，新任期归入对应届次，历史任务仍指向原任期。区间采用左闭右开。
- 任期内职务以时段保存。主编、部长和部员是组织职务，系统角色由账号授予。老师及三审人可直接登记为人员并获得系统权限和指定项目的审核资格。
- 结束任期的同一条写入会停用该人员的账号。重新加入后，由管理员复核并启用账号。

## 活动与工作

- 活动包含独立项目，项目包含具体工作。活动完成率按必需项目等权计算。独立摄影默认以必需工作完成为交付条件，也可配置为需要审核发布的项目。
- 撰稿和秀米排版各有一个在任指派名额。摄影、视频拍摄可多人参加。部员剪辑可多人参加，部长亲自剪辑只允许一名部长。撤销指派后可以补派，历史行保留。
- 指派和贡献独立记录。临时协作者可登记实际贡献。摄影及视频原素材登记归属人员，便于按人筛选。工作量单位是贡献登记条数和实际分钟，责编和审核另计；审核以实际审核决定计数。
- Web 扩展 14 支持项目负责人按原因作废误登工时。同一事务将原记录和登记人归档、释放单人名额并写入审计，原有统计和送审校验继续使用有效记录。未发布任务若因纠错失去最后一条有效工时，从已完成回到进行中。已发布项目可订正统计，保留当时的发布和结项历史。
- 相机预约采用左闭右开区间。归还记录保留实际归还时间。到期未归还仍显示在用，且后续预约无法领用同一设备，直至归还。

## 送审、修改与发布

| 项目 | 提交与审核顺序 |
| --- | --- |
| 微信推文 | 原稿与素材 → 排版人员提交秀米预览 → 部长 → 排版人员同步草稿箱并提交微信预览 → 主编 → 二审 → 按活动启用三审 → 项目主编登记正式发布 |
| 部员剪辑视频 | 部员提交成片 → 部长 → 主编 → 二审 → 按活动启用三审 → 发布 |
| 部长亲自剪辑视频 | 部长提交成片 → 主编 → 二审 → 按活动启用三审 → 发布 |
| 需审核的其他项目 | 交付人员提交成果 → 部长 → 主编 → 二审 → 按活动启用三审 → 发布 |

- 每个项目有独立的审核人名单。二审通过时读取活动三审开关并固定在该版本，当时启用三审才交给三审人。部长、主编和二审审核名单在项目首次送审后固定，三审人员可在首次交三审前补配。
- 微信预览须承接已通过部长审批的秀米版本。主编退回直接交部长，部长将修改交回原排版人员，排版人员重新提交秀米版本。部长退回秀米或部员视频时可直接交回提交人。老师退回部员视频时先交部长，由部长转回原提交人。部长剪辑视频退回时交回该部长。
- 当前版本的所有适用审核均通过、已交待发布且必需工作完成后，才可登记发布。每个项目登记一次正式发布，同一版本的渠道链接保存在该记录中。
- 对推文，扩展 14 在主编登记发布的事务内同步完成具备有效工时的必做任务，已受阻或取消的必做任务需要负责人核实。任一检查失败时，发布、任务状态和历史写入全部回滚。同一活动中其他项目继续按各自的进度计算。
- Word 原稿、照片和视频保存在归档目录或文件存储，秀米和微信预览记录外部链接。每次提交保留其绑定的素材和审核意见。素材复用时追加项目关联，项目和历史版本各自保留对文件元数据的引用。
