# Web 第一阶段验证记录

运行环境为 Windows 11、Python 3.14.6、MySQL 8.0.46 和本机 Microsoft Edge。

## 实施

- Flask 提供中文登录页和共用工作台布局。登录后根据账号的角色和授权显示任务、待审菜单。
- `/api/me` 返回本人身份；任务列表和详情按当前在任指派过滤；待审列表和详情按当前审核交接人过滤。API 独立检查登录状态、功能权限和资源归属。
- 账号使用原有 Argon2id 字段。Web 扩展增加 `web_session`、一个任务查询视图、四个认证过程和一个会话撤销触发器。会话令牌数据库中仅保存 SHA-256 摘要；退出、账号停用和密码变更可撤销会话。每次请求重新读取授权。
- 应用使用新的 `boya_web_auth` 权限角色。该角色可查询允许的视图及调用认证过程。管理员账号可在开发环境使用交互式命令建立。

以上扩展从 [Web SQL 脚本](../database/11_web_auth.sql) 加载，本轮应用环境为独立实验实例。正式库的 Web 扩展及账号依照前期确认约定另行审查部署。
